# Dhanush K – Developer Portfolio

A modern and interactive personal portfolio website built to showcase my technical skills, projects, education, internship experience, and certifications.

---

## Key Features

- **Hero Section:** Professional introduction with profile spotlight, animated headline, core stack badges, and quick resume access.
- **About Me:** Academic background and career interests.
- **Technical Skills:** Organized display of programming languages, frameworks, databases, and development tools.
- **Projects:** Showcase of full-stack development projects with descriptions and technology details.
- **Experience:** Internship details and professional learning experience.
- **Education:** Academic qualifications and achievements.
- **Certifications:** Display of completed courses and certifications.
- **Contact:** Contact information and message form.
- **Resume:** View and download resume options.

---

## Tech Stack

- **Frontend:** React.js, JavaScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Version Control:** Git & GitHub

## Installation & Setup

### Prerequisites

- Node.js
- npm

### Steps

1. Clone the repository:

```bash
git clone https://github.com/dhanush0806/Developer_Portfolio.git
```

2. Navigate to the project directory:

```bash
cd Developer_Portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.
